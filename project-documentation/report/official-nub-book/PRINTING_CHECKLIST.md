# NUB Project Book Printing Checklist

This folder follows the supplied Northern University Bangladesh CSE templates.

## Final report setup

- Paper: A4, 210 mm x 297 mm
- Body: Times, 12 pt, 1.5 line spacing
- Main margins: 1 inch; official special margins are retained for front matter
- Submission month: October 2026
- Official monogram: `figures/nub_monogram.png`
- Cover reverse: intentionally blank
- Main text: black and white; use color only where figures require it

## Physical book

- Hard cover color: black
- Paper: good-quality white bond, preferably 80 GSM
- Number of copies: 3 group members + 3 = 6 copies
- Print and bind only after supervisor or department approval
